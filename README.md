🧮 Expression Converter: Infix, Postfix & Prefix

Bu proje, matematiksel ifadelerin farklı gösterim biçimleri arasındaki dönüşümü ve bu süreçlerin C# Windows Forms arayüzü ile görselleştirilmesini sağlayan bir algoritma uygulamasıdır.

🛠️ Teknik Özellikler

Dil: C#

Arayüz: Windows Forms (WinForms)

Veri Yapıları: Stack (Yığın) tabanlı veri işleme.

Kapsam: Infix gösterimden Postfix ve Prefix formlarına dinamik dönüşüm.

🎯 Öne Çıkan İşlevler

Dönüşüm Algoritmaları: Operatör önceliklerini dikkate alarak karmaşık matematiksel ifadelerin makine diline (Postfix/Prefix) çevrilmesi.

Görsel Takip: C# Form arayüzü sayesinde dönüşüm adımlarının kullanıcı dostu bir panel üzerinden izlenebilmesi.

Hata Yönetimi: Geçersiz matematiksel ifadelerin tespit edilmesi ve kullanıcıya bildirilmesi.

💡 Kazanımlar

Stack (Yığın) veri yapısının algoritmik problemlerdeki etkin kullanımı.

C# Form bileşenleri ile backend mantığının (business logic) entegrasyonu.

Matematiksel ifadelerin ayrıştırılması (parsing) ve operatör hiyerarşisi yönetimi.
